# 🌿 Paradise Nursery Shopping Application

An e-commerce shopping cart for house plants built with React + Redux Toolkit.

## Features
- Landing page with shop button
- Product listing with two sections (Aromatic & Medicinal Plants)
- Add to cart functionality
- Cart with quantity adjustment and delete
- Real-time cart count in navbar
- Continue shopping & checkout buttons

## Tech Stack
- React 18
- Redux Toolkit
- React Router DOM
- Vite

## Installation
```bash
npm install
npm run dev
